# 피클 기록 (data/vector.json)

나란히 앱의 '피클' 칸에 보이는 실제 기록이에요. 이 파일만 고쳐서 올리면 앱을 열 때마다 새 내용을 받아 갑니다.
(앱을 다시 올릴 필요 없어요. 화면 파일과 기록이 따로 있어서, 기록만 바꾸면 됩니다.)

## 모양

```json
{
  "updatedAt": "2026-11-21T14:55:00+09:00",
  "days": [
    {
      "date": "2026-11-21",
      "updatedAt": "2026-11-21T14:55:00+09:00",
      "doing": "지금 하는 일 한 줄",
      "next": { "at": "17:00", "text": "다음에 예약된 일" },
      "done": [
        { "at": "08:15", "text": "오늘 끝낸 일" }
      ]
    }
  ]
}
```

- `date` — 한국 날짜(YYYY-MM-DD). 그날의 '오늘' 칸에 들어가고, 날이 지나면 '지난 날들'로 내려갑니다.
- `doing` — 그날 피클 칸의 큰 글씨 한 줄. 없으면 그날은 비어 보입니다.
- `next` — '다음' 줄(시각 + 할 일). 없으면 안 보입니다.
- `done` — '오늘 한 일 N가지' 접이식 목록. 최근 것부터 넣어 주세요.
- `updatedAt` — 그 기록을 만든 시각. 앱에 "오후 2:55 갱신"처럼 표시됩니다.

## 지켜 주세요

- 전화번호·집주소·이메일 같은 개인정보는 넣지 마세요. 이 저장소는 공개돼 있습니다.
- 윤진 님이 앱에서 '직접 넣기'로 적은 줄이 있으면 그 줄이 먼저 보입니다. 지우면 다시 이 파일의 기록이 보입니다.
- '샘플 기록 같이 보기'가 켜져 있어도 이 파일의 기록은 그대로 보입니다(샘플은 지난 날들에만 덧붙습니다).
